# Клинический калькулятор ишемического инсульта v2.0

> **Специализированная система поддержки принятия врачебных решений (СППР)**  
> Разработана в строгом соответствии с **Клиническим протоколом «Фармакотерапия и хирургическое лечение пациентов с острыми нарушениями мозгового кровообращения»**, утвержденным **Постановлением Министерства здравоохранения Республики Беларусь № 1 от 05.01.2026**.

---

## 📋 О проекте

Веб-приложение предназначено для врачей-неврологов, анестезиологов-реаниматологов, врачей скорой медицинской помощи и рентгенэндоваскулярных хирургов инсультных отделений и ангиографических центров.

Система автоматизирует:
1. **Этиологическую классификацию TOAST 2.0** с дифференциацией криптогенного эмболического инсульта (**ESUS**);
2. **Топографическую классификацию OCSP** (TACS, PACS, LACS, POCS);
3. **Оценку показаний к экстренной реперфузии** — системному тромболизису (**ТЛТ**) и тромбэкстракции (**ВСТЭ**);
4. **Персонализированный антитромботический протокол** — выбор ПОАК/Варфарина, прецизионные сроки старта по правилу дней, схемы ДААТ и COMPASS;
5. **Скрининг злокачественного полушарного и мозжечкового инфаркта** с маршрутизацией на декомпрессивную трепанацию черепа;
6. **Формирование готового врачебного протокола-заключения** для ЭМК и печати.

| **п. 30–38** | Механическая тромбэкстракция (ВСТЭ) | Окно 0–6 ч (ASPECT $\ge 6$, NIHSS $\ge 6$); окно 6–24 ч (DAWN/DEFUSE-3: ядро $<70$ мл, пенумбра $>15$ мл); окклюзия БА до 24 ч |
| **п. 43.1, Таблица** | Сроки назначения/возобновления ОАК | 1-е сутки (ТИА / $<1.5$ см), 3-и сутки ($1.5–3.0$ см), 6-е сутки ($>3.0$ см при контроле КТ), 10–14-е сутки (тяжелый/геморрагия) |
| **Приложение 14** | Выбор ПОАК при фибрилляции предсердий | Апиксабан / Ривароксабан / Дабигатран / Варфарин с учетом CrCl, ЖКК, дисфагии/зонда и массы тела |
| **п. 43.2** | Двойная антитромбоцитарная терапия (ДААТ) | Клопидогрел + АСК 21 день (NIHSS $\le 3$, ABCD² $\ge 4$); Тикагрелор + АСК 30 дней (NIHSS $\le 5$); схема COMPASS |

| **Приложение 13** | Шкала HAS-BLED | Оценка риска кровотечений при назначении антикоагулянтов (0–9 баллов) |

## ⚡ Ключевые функциональные возможности

### 1. Пошаговый мастер клинических данных (6 шагов)
- **Шаг 1: Анамнез и факторы риска** — возраст, пол, преморбидный статус (pre-mRS), ИБС, ХСН, диабет, анамнез инсульта/ТИА/ВМК.
- **Шаг 2: Неврологический статус** — время от дебюта (часы), Wake-Up инсульты, синдромы (корковые, гемианопсия, мозжечковые), интеграция с интерактивным калькулятором **NIHSS**.
- **Шаг 3: Сосудистый статус (БЦА)** — процент стеноза целевой артерии по NASCET, нестабильность бляшки, тандемный стеноз, синдром «водораздела».
- **Шаг 4: Гемодинамика и кардио-статус** — мониторинг АД, гликемии, тромбоцитов, верификация кардиальных источников высокого и низкого риска.
- **Шаг 5: Нейровизуализация и ASPECT** — модальность (КТ/МРТ/КТ-ангио/перфузия), размеры очага, окклюзия крупных артерий (ВСА, М1, М2, БА), интерактивная оценка ASPECT (0–10) и pc-ASPECT.
- **Шаг 6: Фармакологический профиль** — клиренс креатинина (CrCl), риск ЖКК, дисфагия (зондовое питание), масса тела, выбор схемы антитромботической терапии.

### 2. Результаты и экспертный вывод
- **Диагностический спектр подтипов TOAST 2.0:** взвешенный процентный расчет вероятности каждого из 5 подтипов (LAA, CE, SVO, ODE, UDE) с определением ведущего этиологического механизма.
- **Топографический синдром OCSP** с указанием бассейна васкуляризации.
- **Блок реперфузии:** четкий вердикт по ТЛТ и ВСТЭ, расчет доз алтеплазы, анализ противопоказаний.
- **Персонализированный план антитромботической терапии:** точный день старта антикоагулянтов или длительность курса ДААТ, режим дозирования, правила безопасности.
- **Экстренные предупреждения:** баннер подозрения на злокачественный отек мозга со срочным планом действий для консилиума.
- **Матрица предикторов:** прозрачная расшифровка вклада каждого клинического фактора в баллы подтипов.

### 3. Сервисные инструменты
- **Библиотека клинических сценариев (6 пресетов):**
  1. *Атеротромботический (LAA)* — симптомный стеноз ВСА 75%, кандидат на ТЛТ+ВСТЭ;
  2. *Кардиоэмболический (CE)* — фибрилляция предсердий, эмболический инфаркт;
  3. *Лакунарный (SVO)* — чистый двигательный инсульт, очаг 12 мм;
  4. *Редкая этиология (ODE)* — острая диссекция внутренней сонной артерии у молодого пациента;
  5. *Злокачественный инфаркт СМА* — массивный отек, смещение срединных структур, предписание к декомпрессии;
  6. *Криптогенный эмболический (ESUS)* — план углубленного кардиологического поиска.
- **Врачебный протокол-заключение (Print / Export):** форматированный бланк медицинского заключения для вклеивания в историю болезни или экспорта в ЭМК.
- **Справочник по Протоколу МЗ РБ № 1:** встроенные таблицы критериев TOAST, окон реперфузии, шкал дозирования ПОАК и хирургических показаний.
- **Локальный архив случаев:** сохранение расчетов в браузере врача с возможностью быстрой загрузки.

## 📚 Клинические источники и нормативная литература

Алгоритмы диагностики, классификации, шкалы и терапевтические рекомендации приложения базируются на фундаментальных источниках:

1. **Клинический протокол «Фармакотерапия и хирургическое лечение пациентов с острыми нарушениями мозгового кровообращения»**, утвержденный Постановлением Министерства здравоохранения Республики Беларусь № 1 от 05.01.2026.

## 🛠 Технологический стек

- **Фреймворк:** React 19 (TypeScript)
- **Сборщик:** Vite 6
- **Стилизация:** Tailwind CSS v4
- **Иконки:** Lucide React
- **Анимации:** Motion (`motion/react`)
- **Архитектура:** Чистая клиентская модульная модель с мгновенным локальным реактивным пересчетом клинических алгоритмов (без передачи персональных данных пациентов во внешнюю сеть).

## 🚀 Установка и запуск

### Предварительные требования
- **Node.js** версии 18.x или выше;
- Менеджер пакетов **npm** или **bun**.

### 1. Клонирование репозитория
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd stroke-calc
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск в режиме разработки
```bash
npm run dev
```
Приложение будет доступно по адресу: `http://localhost:3000`

### 4. Проверка типов и линтинг
```bash
npm run lint
```

### 5. Сборка для производственного окружения (Production)
```bash
npm run build
```
Скомпилированные статические файлы будут размещены в директории `dist/`.
